Fonts load from Google Fonts (Cinzel, Cormorant Garamond, Great Vibes, Poppins)
via the <link> in index.html.

To self-host instead — worth doing if the site must work offline or you want
to drop the third-party request — download the four families here and replace
that <link> with an @font-face block in style.css. Use font-display: swap.
